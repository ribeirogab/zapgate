# Security policy

## Report a vulnerability

Do not open a public issue for a vulnerability. Report it privately through [GitHub security advisories](https://github.com/ribeirogab/zapgate/security/advisories/new).

Tell us what you found, how to reproduce it, and what an attacker can do with it.

## Supported versions

Only the latest release gets security fixes.

## Scope

In scope: the zapgate server, its OAuth flow, its access control, its approval flow, its container image and its deploy files.

Out of scope: bans by WhatsApp, vulnerabilities in WhatsApp itself, and vulnerabilities in a proxy or tunnel that you put in front of zapgate. Read [docs/security.md](docs/security.md) for the risks that zapgate knows and accepts.
